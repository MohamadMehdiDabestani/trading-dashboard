# APINEX.md

Project guidelines and conventions for APInex CLI autonomous coding assistant.

## Overview
- **Project**: trading-dashboard
- **Package Manager**: `pnpm`

## Development Commands
- **build**: `pnpm run build` (`turbo run build`)
- **dev**: `pnpm run dev` (`turbo run dev`)
- **lint**: `pnpm run lint` (`turbo run lint`)

## Architecture & Conventions
- **Consistency**: Follow the conventions and patterns in the existing codebase.
- **Surgical Changes**: Make minimal, precise changes; do not reformat unrelated files.
- **Verification**: Run tests and type-checks after editing code to verify correctness.
- **Safety**: Do not commit secrets, API keys, or private environment variables.
